# Model Arena launch review

Review date: 1 October 2026. Scope is the original comparison workflow plus authenticated owner-scoped browser state and shared UI. Local integrated acceptance, deployed free checks, one controlled HF generation and ordinary live restoration are verified.

- **Identity changes, high impact:** the workspace remounts by verified owner ID, retains its original session epoch for queued jobs and async readers, and aborts pending fetch/FileReader work on unmount. Late headers, JSON, 401s and failed session refreshes cannot invalidate a later login. A current session failure hides the workspace. Server authorization remains authoritative.
- **Shared-device state, high impact:** comparisons use owner-keyed localStorage. Legacy global work is not adopted; only the retired persisted access key is scrubbed. Passwords are not stored. Browser storage is not encryption and remains a documented device-local limitation.
- **Provider spend, high impact:** prepared examples use a server-owned fixture identity on normal Run/Grade routes. Edits visibly exit that context. Catalogs load independently and suggestion chips include only verified-price routes. No run/grade is triggered by render, theme change or catalog refresh. Stop prevents further queue dispatch; it cannot retract an in-flight provider call.
- **Misleading comparisons, medium impact:** prompt edits invalidate that row’s responses/grades; reference or grader changes invalidate relevant grades; shared system/corpus/placement/decoding/model changes invalidate comparison output. Interrupted browser jobs restore as interrupted errors. Prepared results and scores remain explicitly labeled.
- **Imports/exports, medium impact:** bounded prompt/reference/corpus/file sizes, unique prompt IDs and invalid-data errors preserve a usable matrix. CSV formulas are neutralized. Exports assert the workspace identity before creating browser downloads. Corrupt saved state is not silently imported or overwritten before an explicit edit.
- **Usability, medium impact:** deterministic initial sample IDs, visible account labels/errors/busy states, named icon controls, semantic light/dark surfaces and inner table scrolling are implemented. Root in-app browser review passed both themes at desktop/390px.
